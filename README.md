# Learn to Cloud — Phase 0: Verification & Foundations

This repository documents my completion of **Phase 0** of the [Learn to Cloud](https://learntocloud.guide) roadmap. The goal of this phase is to establish a solid technical baseline—covering version control, the command line, documentation, and foundational IT/networking concepts—before moving into Linux, networking, and cloud infrastructure.

- [x] **Markdown Documentation:** Structure clean, readable technical documentation using Markdown syntax.

## 📝 Key Takeaways & Notes

### 1. Git & Version Control Workflow
* Configured global Git identity (`user.name` and `user.email`) and linked SSH keys to GitHub for passwordless authentication.
* Practiced standard version control hygiene: atomic commits, meaningful commit messages, and working with `.gitignore`.

### 2. Command Line Basics
* Mastered core file manipulation (`ls`, `cd`, `pwd`, `mkdir`, `touch`, `cp`, `mv`, `rm`) and file inspection (`cat`, `less`, `head`, `tail`, `grep`).
* Understood relative vs. absolute file paths and basic file permissions.

### 3. Technical Writing with Markdown
* Created this `README.md` to practice formatting headers, lists, code blocks, links, and task checklists—an essential skill for documenting infrastructure and runbooks.
